# Contributing

qlink is a **very early development version**. It is under active development, and this repository is a public preview of the progress. The source code is not published here.

## How to take part

| You want to | Use |
| --- | --- |
| Suggest a feature, world or tool | [Idea issue](../../issues/new?template=idea.yml) |
| Comment on a render, video or document | [Feedback issue](../../issues/new?template=feedback.yml) |
| Test future builds | [Tester interest issue](../../issues/new?template=tester-interest.yml) |
| Help with development, art or sound | [Offer to help issue](../../issues/new?template=offer-help.yml) |
| Ask a question or start a discussion | [Discussions](../../discussions) |

Test versions and collaboration are offered **by invitation** later on. Registering interest does not guarantee an invitation.

## Labels

- **Type:** `idea`, `feedback`, `tester interest`, `collaboration`, `question`
- **Area:** `area: streaming`, `area: rendering`, `area: avatars`, `area: simulation`, `area: worlds`, `area: tools`
- **Status:** `status: needs triage`, `status: under consideration`, `status: planned`, `status: not planned`

## Ground rules

- Follow the [project principles](README.md#principles): clean-room work, no circumvention of authentication, DRM or encryption, and evidence before claims.
- Do not post proprietary code, decompiled material, private SDK headers or leaked assets.
- Do not post credentials, account data, serial numbers or device identifiers.
- Be respectful and constructive.
